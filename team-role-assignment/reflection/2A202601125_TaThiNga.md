## 1. Công việc đã thực hiện

- Xây dựng các đoạn script gọi GitHub REST API (`src/github_fetcher.py`, `src/repo_fetcher.py`) để cào dữ liệu commit, PR, và ngôn ngữ lập trình của các tài khoản.
- Viết prompt AI đóng vai trò như một Project Manager, đọc các file README/requirements của dự án để phân rã thành các task nhỏ (`src/project_analyzer.py`).

## 2. Khó khăn gặp phải

Giới hạn (Rate Limit) của GitHub API là một rào cản lớn khi cào dữ liệu liên tục trong quá trình test. Ngoài ra, việc bảo LLM tự động nhận diện "cần làm những task gì" từ một file README sơ sài đôi khi mang lại kết quả quá chung chung, khó để ghép việc sau này.

## 3. Cách giải quyết & Bài học rút ra

Để giải quyết Rate Limit, mình đã thiết lập cơ chế dùng GitHub Token trong biến môi trường (`.env`) và thêm logic bắt lỗi, tạm dừng khi hết lượt gọi API. Đối với phần AI phân tích dự án, mình đã cải tiến prompt bằng cách đưa thêm các ví dụ (Few-shot prompting) về cách chia task cụ thể (frontend, backend, AI, test). Kỹ năng làm việc với API ngoại và kỹ thuật Few-shot prompting của mình đã được củng cố rất nhiều.
